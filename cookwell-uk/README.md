# CookWell UK prototype

This is the first local, responsive front-end prototype for CookWell UK. It uses mock data only—there is no account, real retailer pricing, or health-data storage.

## Run it locally

Open `index.html` in a modern browser. For best results, use any local static-file server from the `cookwell-uk` folder.

## Included

- Four responsive screens: Today, Plan, Shop & Kitchen, Progress
- Sample 7-day plan with a discovery meal and cuisine variety
- Meal-swap interaction
- Editable prices and a dynamic £40 budget total
- Purchased-item/inventory interaction
- Beginner cook mode
- Manual, unit-labelled glucose/weight/step log prototype
